# 找校科 CSV 欄位規格

學校詳情頁的六個分頁不是全部都應該由 CSV 提供。CSV 負責學校與校科資料；「決策操作」則由使用者在網站中收藏、分層、備註與比較。

## 目前基本欄位

```text
排名,學校代碼,學校名稱,公私立,招生區,學制分類,男女校,縣市,區,地址,官網,電話,科系與名額,簡章招生名額,招生名額,最低錄取分數,分數年度,分數來源備註,資優班/特色班,排序分數
```

## 新增個別欄位

以下欄位都是選填。CSV 沒有填寫時，詳情頁會顯示「待補 CSV 欄位」，不會自行推估。

| CSV 欄位 | 對應分頁 | 用途 |
| --- | --- | --- |
| `課程方向` | 學習內容 | 學習重點、課程特色與方向 |
| `實習／專題` | 學習內容 | 實習、專題、產學或作品內容 |
| `適合學生` | 學習內容 | 學校或科別公開的適合對象說明 |
| `正式簡章連結` | 招生資訊 | 直接連到當年度正式簡章 |
| `交通方式` | 生活條件 | 公車、火車、接駁或主要交通方式 |
| `通勤資訊` | 生活條件 | 通勤時間、路線或需自行核對的資訊 |
| `住宿資訊` | 生活條件 | 宿舍、住宿或租屋相關公開資訊 |
| `生活資料來源` | 生活條件 | 交通與住宿資料的來源 |

## 不放進 CSV 的欄位

`決策操作` 不放在學校 CSV。以下是使用者自己的規劃資料，由網站保存：

- 挑戰／適中／穩定分層
- 志願順序
- 個人備註與「為什麼想選」
- 家長／學生觀點
- 加入比較與家庭討論摘要

## 填寫原則

1. 一列代表一所學校；科別可放在 `科系與名額`，以 `；` 分隔。
2. 不確定的欄位留白，不要填入猜測或保證錄取的文字。
3. 每個數字要保留資料年度與來源備註。
4. 連結欄位使用完整 `https://` 網址。
5. 使用 UTF-8（建議含 BOM）儲存，避免繁體中文亂碼。
