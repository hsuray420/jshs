# 嘉南屏花東澎金積分試算 TDD 證據

來源規格為使用者提供的 `115免試入學_嘉南屏花東澎金_開發規格.md` 與七份 115 學年度規則 JSON。

## 使用者旅程

- 學生選擇嘉義、臺南、屏東、花蓮、臺東、澎湖或金門時，系統載入該區規則，不借用其他區公式。
- 學生輸入會考、志願序與可佐證項目後，系統採用該區封頂與折算規則；必要資料不足時回傳 incomplete。
- 花蓮學生需依目標學校附表補上「各校自訂其他項」；系統不以全區假公式替代。

## RED → GREEN

| 階段 | 證據 | 結果 |
| --- | --- | --- |
| RED | `node --experimental-strip-types --test tests/admission-rules.test.mjs` | 新增的七區開放測試失敗：嘉義尚未列為可試算區。 |
| GREEN | 同一命令 | 14/14 通過；七區各自的資料來源、總分上限、志願序、封頂與會考案例均通過。 |

## 測試保證

| 保證 | 測試 | 結果 |
| --- | --- | --- |
| 七區讀取各自 115 JSON 的名稱、總分、來源 ID 與欄位 | `嘉南屏花東澎金七區使用各自的 115 官方規則 JSON 開放試算` | PASS |
| 嘉義、臺南、屏東、花蓮、臺東、澎湖、金門各自套用不同志願序、封頂與會考規則 | `嘉南屏花東澎金七區各自套用志願序、封頂與會考公式` | PASS |
| 所有 15 區維持可追溯的試算流程 | `15 個就學區都能完成一次透明的成績試算` | PASS |

## 補充

本專案目前沒有 coverage script；以現有 Node test runner 執行目標規則測試與完整測試套件作為驗證。競賽紀錄與花蓮校訂項仍必須以可佐證的官方附表資料輸入，避免將未提供的名次換算表推測成分數。
