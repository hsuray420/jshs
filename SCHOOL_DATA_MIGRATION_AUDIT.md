# School Data Migration Audit

## Current Contract

The national school discovery runtime now uses seven enabled regional CSV files
under `content/schools/regions/` as the source of truth. Enabled status is
declared in `lib/school-data/regional-loader.mjs`; CSV existence alone does not
make a region public.

Build output is regenerated from those seven CSV files:

| Surface | Generated source | Runtime use |
|---|---|---|
| `/schools`, detail, map, compare, commute | `content/schools/generated/schools.json` | Unique school entities keyed by `學校代碼` |
| `/api/schools.csv` | `public/data/schools.csv` | 495-row aggregate of enabled regional CSV rows |
| Search and sitemap | generated summaries and school-code index | School-code identity |

## Removed Legacy Sources

The retired manually maintained national entity and relation CSV artifacts have
been removed from runtime code, generated output, and repository data folders.
The compatibility CSV endpoint now returns the generated regional aggregate
instead of a hand-maintained master file.

## Retained Files Outside National School Discovery

Region folders may still contain historical inputs such as `admission-history.csv`
for other tools. Those records remain separate historical reference material and
are not merged into the current 115 school entity fields.

## Validation

`SCHOOL_DATA_AUDIT.md` is regenerated by `pnpm run schools:generate` and records
the active region files, row counts, schema checks, source hashes, warnings, and
errors. Current expected public-school totals are 7 enabled regions, 495 regional
CSV rows, and 448 unique school entities.
