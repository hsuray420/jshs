# JSHS.CC Homepage Pixel Specification

## Canonical target
`docs/design-reference/homepage/homepage-master-reference.jpg` (1225×1284px)

This image is the layout specification, not inspiration. Reproduce all controllable visual properties as closely as technically possible: composition, header, container width, hero split, spacing, typography hierarchy, search geometry, feature-entry geometry, school-card geometry, radii, borders, shadows, image boxes and responsive hierarchy.

## Truth rule
The screenshot controls visual geometry, NOT factual claims. Never copy unsupported mock statistics or nonexistent features. No verified data = no number. Audit actual routes before showing feature entries.

## Hero asset
Use `docs/design-reference/homepage/hero-students-production.png`. Keep students visually concentrated on the right and preserve a clean left copy area. Match the master reference crop/position/overlay as closely as possible.

## Header
Match `reference-header.jpg`: thin white header, centered content frame, restrained navigation and actions. Navigation text must correspond to real routes.

## Hero
Match `reference-hero.jpg`: eyebrow, large two-line headline footprint, body-copy width, search dimensions, right-heavy imagery and vertical rhythm. Copy may change for factual accuracy.

## Feature entries
Only show real currently usable features. Preserve the compact icon/title/subtitle/separator treatment. Do not invent entries to force a four-column row.

## Popular schools
Match `reference-popular-schools.jpg` geometry. `reference-school-card-*.jpg` are visual references only, NOT authentic photos of named schools. Production cards use admin-approved images or the official fallback while keeping identical image-box geometry.

## Brand section
Match `reference-brand-section.jpg` composition. The mock statistics are NOT approved. Remove unsupported numbers. Preserve editorial headline, supporting copy, dark CTA, pale visual field and whitespace without fabricating metrics.

## Responsive
Desktop and mobile are first-class. Do not merely shrink desktop. Preserve hierarchy, focal crop, touch targets and section rhythm.

## Verification
Use production-like preview and compare actual screenshots side-by-side with the canonical reference. Iterate on x/y placement, width, height, max-width, margin, padding, gap, font size/weight/line-height, radius, border, shadow, aspect ratio and object-position.

Completion requires: `Controllable visual differences: NONE`.

Allowed differences are only truthful content differences, real text length, and unavailable approved school photography.

Do not commit, push or deploy before human review.
