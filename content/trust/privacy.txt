全國國中升學資訊網（以下稱「本站」）重視使用者的隱私及個人資料安全。本政策說明本站在提供升學資訊查詢、積分試算、學校比較、規劃保存、只讀分享、錯誤回報及其他功能時，如何蒐集、處理、利用、保存及保護相關資料。

請在使用本站前閱讀本政策。若使用者不同意本政策所說明的資料處理方式，應停止使用需要相關資料處理的功能。單純瀏覽本站不代表使用者同意本站將資料用於本政策未說明的其他目的。

一、適用範圍

1. 本政策適用於https://jshs.cc網域、其子網域，以及由本站直接提供並明確連結至本政策的網站與功能。
2. 本站可能包含教育主管機關、招生委員會、學校、地圖、交通服務或其他第三方網站的連結。
3. 使用者離開本站後，應適用該第三方的隱私權政策，本站無法控制或代替第三方說明其資料處理方式。
4. 本政策不適用於使用者自行將內容傳送給其他人、發布至社群平臺或交由其他服務處理的情形。

 二、個人資料蒐集者與聯絡方式

* 網站名稱：全國國中升學資訊網
* 網站網址：https://jshs.cc
* 隱私權聯絡信箱：jshs.contact@gmail.com

三、本站可能處理的資料

本站依使用者實際使用的功能，可能處理下列資料。並非每位使用者都會被蒐集全部項目。

1. 瀏覽器本機資料
可能包含首頁進度、篩選條件、顯示偏好、功能狀態，以及其他儲存在瀏覽器中的資料。這些資料主要用於保存使用進度、維持個人偏好及提供網站基本功能。
2. 規劃內容
可能包含使用者選擇的地區、學校、志願、試算條件、備註、排序方式及相關規劃紀錄，主要用於保存及顯示「我的規劃」內容。
3. 分享快照
當使用者主動建立分享內容時，網站可能產生只讀的規劃快照及相關網址片段，讓持有完整網址的人查看指定內容。
4. 識別資訊
可能包含規劃識別碼、分享識別資訊、工作階段識別資訊，或功能運作所需的隨機代碼，用於對應正確的規劃、分享內容或工作階段。
5. 技術與連線資料
可能包含 IP 位址、請求時間、請求頁面、瀏覽器與裝置類型、作業系統、來源頁面、錯誤紀錄、安全紀錄及基本使用狀態。這些資料主要用於傳送網頁、維持服務安全、防止濫用、排查問題及改善網站。
6. 聯絡與回報資料
當使用者主動聯絡我們時，可能提供電子郵件、其他聯絡方式、回報內容、附件及往來紀錄。這些資料用於回覆問題、處理錯誤回報、權利申請、安全事件或合作聯繫。
7. 法令與爭議處理資料
為處理權利申請、申訴或爭議，我們可能在必要範圍內處理身分核對資料、申請內容及相關紀錄，用於履行法律義務、確認申請人身分、保護各方權利及解決爭議。

本站原則上不要求使用者提供身分證字號、完整住址、電話、帳號密碼、金融資料、醫療資料、證件影本或其他與升學規劃功能無關的敏感資料。使用者不應在備註、規劃、回饋或回報內容中填寫前述資料。

四、瀏覽器本機儲存與暫存資料

1. 未登入時，首頁進度、篩選條件與部分偏好可能保存在使用者裝置的瀏覽器本機儲存空間、工作階段儲存空間、Cookies 或其他必要的瀏覽器儲存機制中。
2. 前述資料原則上保留在使用者自己的裝置中，不會只因瀏覽本站就自動成為公開頁面。
3. 使用者可以透過瀏覽器設定查看、限制或清除相關資料。
4. 清除瀏覽資料、更換裝置、使用無痕模式、重新安裝瀏覽器或瀏覽器自動清理後，相關進度及偏好可能無法恢復。
5. 使用者拒絕或停用必要的瀏覽器儲存功能時，部分頁面狀態、規劃進度、偏好或安全功能可能無法正常運作。
6. 除非本政策另有說明，本站不會因瀏覽器本機保存功能而取得使用者裝置中與本站服務無關的其他檔案或資料。

五、「我的規劃」功能

1. 「我的規劃」功能可能使用本站提供的識別方式保存及讀取使用者建立的規劃內容。
2. 規劃內容可能包括使用者選擇的學校、志願順序、篩選條件、試算條件、備註及其他由使用者主動輸入的內容。
3. 本站可能透過隨機識別資訊、限制公開列表、要求搜尋引擎不要索引或其他合理措施，降低規劃內容被一般搜尋發現的可能性。
4. 「禁止搜尋引擎索引」或未列在公開頁面，不等同於加密、登入驗證或絕對保密。
5. 任何取得有效識別資訊、完整規劃網址或可存取裝置的人，仍可能開啟相關內容。
6. 使用者應妥善保管規劃識別資訊及網址，不應將含有個人資料的規劃內容傳送給不信任的對象。
7. 使用者不應把本站當作成績單、報名文件、證明文件或其他重要資料的唯一保存位置，並應自行保留必要備份。

六、只讀分享與網址片段

1. 使用者可主動建立只讀分享，將選定的規劃內容或快照提供給其他人查看。
2. 只讀分享可能使用網址片段傳遞快照。網址片段通常不會隨一般 HTTP 頁面請求直接傳送至伺服器，但仍可由正在顯示該網址的瀏覽器程式、使用者裝置、瀏覽器擴充功能或取得完整網址的人讀取。
3. 持有完整分享網址的人可能查看、複製、截圖、轉傳或另行保存分享內容。
4. 本站無法控制接收者後續如何處理已取得的內容。
5. 使用者建立分享前，應確認內容不包含姓名、電話、地址、准考證號、身分證字號、成績單、帳號密碼或其他不必要的個人資料。
6. 只讀分享設為不可被搜尋引擎索引，只代表本站採取措施要求搜尋引擎不要建立索引，不保證所有搜尋服務、快取、外部網站或第三方均會遵守。
7. 不可被搜尋引擎索引不代表分享內容只有指定對象能看見。
8. 使用者應自行決定分享對象並妥善保管網址。
9. 若分享網址遭誤傳，應停止使用、刪除或重新建立分享內容；實際可用功能依網站當時提供的操作為準。

1. 使用者連線至本站時，網站主機、內容傳遞網路、安全防護服務或其他必要基礎設施，可能自動產生頁面請求、IP 位址、時間、裝置與瀏覽器類型、錯誤、安全事件及基本使用狀態等技術紀錄。

2. 本站處理技術紀錄的目的包括：

   * 正確傳送網站內容；
   * 維持系統與網路安全；
   * 防止攻擊、詐欺、異常存取及自動化濫用；
   * 排查錯誤、維護服務及回復故障；
   * 了解整體功能使用狀況並改善網站；
   * 履行法令、安全通報或爭議處理義務。

3. 除非法律要求、處理安全事件、保護本站或他人權益，或經使用者另行同意，本站不會將技術紀錄用於建立與服務目的無關的不必要個人檔案。

5. 若未來啟用非必要分析、廣告或追蹤技術，本站將先更新本政策，並依適用法令提供必要告知或選擇機制。

八、蒐集目的與法令依據

本站僅在具備特定目的及適用法令允許的情況下蒐集、處理或利用個人資料，可能依據包括與使用者間的契約或類似契約關係、使用者同意、法律明文規定、維護資訊安全與權利的必要範圍，或其他依法可處理的事由。

主要目的包括：

1. 提供升學資訊查詢、積分試算、學校比較及規劃功能。
2. 保存並顯示使用者選擇的偏好、進度及規劃內容。
3. 依使用者指示建立只讀分享或規劃快照。
4. 維持網站連線、效能、可用性及資訊安全。
5. 防止異常存取、攻擊、詐欺、濫用或違反服務條款的行為。
6. 排查錯誤、回覆問題、處理資料更正及改善服務。
7. 處理個人資料權利申請、安全事件、申訴或法律爭議。
8. 履行適用法令、主管機關或司法機關依法提出的要求。

本站不會在沒有適當法律依據或必要告知的情況下，將蒐集到的資料任意改作與原目的無關的用途。

本站於下列期間內保存或利用資料，並以達成特定目的所必要的範圍為限：
1. 使用者持續使用相關功能或資料仍為提供功能所必要的期間。

3. 法令要求的保存期間。
4. 為維護資訊安全、處理備份、申訴、爭議或法律請求所合理必要的期間。
5. 第三方基礎設施中的技術紀錄及備份，依服務設定、契約及必要安全週期保存。

利用地區
1. 中華民國境內。
2. 本站、網站代管、內容傳遞、安全防護、錯誤監測或其他必要服務提供者設置設備或處理資料的地區。

利用對象
1. 本站營運及維護所必要的人員。
2. 受本站委託提供網站代管、內容傳遞、安全防護、資料儲存、寄信、錯誤監測或技術支援的服務提供者。
3. 使用者主動指定或取得分享網址的對象。
4. 依法有權要求提供資料的主管機關、司法機關或其他公務機關。
5. 為保護本站、使用者或第三人合法權益而有必要接收資料的專業顧問或相關當事人。

利用方式
本站以自動化或非自動化方式進行必要的記錄、儲存、整理、查詢、顯示、傳輸、刪除、安全分析、錯誤排查及其他與前述目的相符的處理。

1. 為提供網站，本站可能使用網站代管、內容傳遞網路、網域解析、安全防護、資料儲存、寄信、錯誤監測或其他技術服務。

十一、資料提供、揭露與對外分享

本站原則上不會任意向第三人提供使用者的個人資料，但下列情形除外：

1. 使用者主動分享、明確同意或要求本站提供。
2. 為提供使用者所要求的功能，而需由受託服務提供者處理。
3. 法律明文規定，或主管機關、司法機關依合法程序要求。
4. 為防止或處理資安事件、詐欺、濫用、重大違法行為或對他人權益的重大危害所必要。
5. 為主張、防禦或處理法律上權利、申訴及爭議所必要。
6. 資料已經合法去識別化，且無法合理識別特定個人。

十二、資料保存、刪除與備份

1. 本站僅在提供功能、維護安全、履行法律義務或處理爭議所必要的期間內保存資料。
2. 蒐集目的消失、保存期限屆滿或已無繼續保存必要時，本站將依適用法令及技術可行性刪除、停止處理、停止利用或進行去識別化。
3. 使用者可自行清除保存在瀏覽器中的本機資料。
4. 使用者如可透過功能刪除規劃或分享內容，可依網站當時提供的操作辦理；如無相應操作，可透過隱私權聯絡信箱提出請求。
5. 資料刪除後，副本可能因備份輪替、資安紀錄、爭議處理或法律義務而在有限期間內暫時保留，且不再用於與保留原因無關的目的。
6. 使用者已提供給第三人、由第三人另行複製保存或已公開發布的內容，本站可能無法從第三人的裝置、帳號或服務中代為刪除。

十三、使用者的個人資料權利

使用者依法得就其個人資料行使下列權利：

1. 查詢或請求閱覽。
2. 請求製給複製本。
3. 請求補充或更正。
4. 請求停止蒐集、處理或利用。
5. 請求刪除。

使用者可透過本政策第二條所列聯絡方式提出申請。為避免資料遭他人冒領、竄改或刪除，本站可能在合理必要範圍內要求驗證申請人的身分或其與相關資料的關聯。

本站將依適用法令及實際資料狀況處理申請。如法律允許本站拒絕、限制或延後處理全部或部分請求，本站將在合理範圍內說明原因。請求閱覽或製給複製本時，本站得依法酌收必要成本費用。

使用者依賴分享識別資訊或瀏覽器本機資料使用服務時，如本站無法合理確認資料與特定個人的關聯，可能需要使用者提供相關識別資訊，才能定位並處理資料。

十四、不提供資料的影響

1. 使用者可自由選擇是否在規劃、備註、回報或其他功能中提供資料。
2. 如使用者不提供特定功能運作所必要的資料，本站可能無法保存規劃、建立分享、回覆問題、處理權利申請或提供相應功能。
3. 使用者停用必要 Cookies、本機儲存或安全功能時，網站的進度保存、偏好、工作階段或部分功能可能無法正常運作。
4. 使用者仍可在功能允許的範圍內，只瀏覽不需要額外輸入資料的公開升學資訊。

十五、資料安全

1. 本站會依服務規模、資料性質及可合理預見的風險，採取合理的技術與管理措施，防止資料遭未經授權的存取、竊取、竄改、毀損、滅失或洩漏。
2. 可能採取的措施包括傳輸加密、權限限制、隨機識別資訊、安全更新、備份、異常流量防護及必要的紀錄與監測。
3. 網際網路、瀏覽器、第三方服務與資訊系統不存在絕對安全的環境，因此本站無法保證資料永遠不會遭到未經授權的存取、洩漏、修改或遺失。
4. 使用者應妥善保管裝置、瀏覽器、規劃識別資訊及分享網址，並避免在公共或共用裝置中保存敏感內容。
5. 本站知悉可能影響使用者權益的個人資料安全事件時，將依事件情況及適用法令採取控制、調查、修復、記錄、通知或通報措施。

十六、敏感資料與錯誤送出

1. 請勿在規劃、備註、回饋、錯誤回報或附件中填寫身分證字號、完整地址、電話、帳號密碼、金融資料、醫療資料、證件影本或其他非必要的敏感資料。
2. 使用者如誤送敏感資料，應儘速透過本政策第二條所列聯絡方式通知本站，並提供足以定位資料的必要資訊。
3. 使用者請勿在通知信中再次附上完整敏感資料。
4. 本站收到通知後，將在合理可行及符合法令的範圍內查找、限制存取、刪除或採取其他適當措施。

十七、未成年人隱私

1. 本站內容可能供未成年學生使用，本站不會因使用者為未成年人而要求提供超出功能必要範圍的個人資料。
2. 未成年人應由法定代理人陪同閱讀本政策，並避免在規劃、備註、分享或回報中提供可直接識別個人的資料。
3. 涉及帳號、付款、持續性服務或依法需要法定代理人同意的功能時，未成年人應先取得法定代理人同意。
